# University Student Registration System

A Python-based University Student Registration System developed using Object-Oriented Programming (OOP) to organise and simplify student registration and academic administration processes.

## About the Project

The University Student Registration System is a console-based application designed to improve the management of student registration activities within a university. It provides separate interfaces for students and university staff, allowing different registration tasks to be handled according to each user's role.

The project demonstrates how Python classes and objects can be used to model a real-world university registration process.

## Problem Statement

Traditional university registration processes may involve long queues, repeated paperwork, delays in verifying student information, and difficulties coordinating between academic and administrative departments.

This project proposes a simple software solution that organises registration activities into a structured workflow, helping demonstrate how digital systems can improve administrative efficiency.

## Objectives

- Simplify the student registration process.
- Organise student information and applications.
- Support module assignment according to programme, academic level, and semester.
- Provide separate functions for different university staff roles.
- Support finance verification, faculty review, and final registry approval.
- Demonstrate practical applications of Object-Oriented Programming in Python.

## Key Features

- Student application and login.
- Student information management.
- Role-based staff access.
- Module assignment by the Year Leader.
- Finance and sponsorship verification.
- Faculty review.
- Final registration approval by the Registry Officer.
- Academic result review and identification of certain result statuses.
- Input validation where implemented.

## User Roles

| Role | Responsibility |
|---|---|
| Student | Applies and provides registration information. |
| Year Leader | Assigns modules and reviews academic results. |
| Finance Officer | Verifies payment or sponsorship information. |
| Faculty Officer | Reviews registration information. |
| Registry Officer | Verifies student details and handles final registration approval. |

## How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in your code editor or terminal.
4. Run the main Python file:

```bash
python main.py
```

If your system uses the Python launcher, you can run:

```bash
py main.py
```

5. Follow the instructions displayed in the terminal.

## Object-Oriented Programming

The project applies OOP concepts, including:

- **Classes and Objects:** Represent students and university staff roles.
- **Encapsulation:** Organises related data and behaviour within classes.
- **Methods:** Perform registration and administrative operations.
- **Modularity:** Separates different responsibilities into individual Python files.

## Limitations

- Data is stored in memory and is not retained after the program closes.
- The current version uses a console-based interface.
- Database integration and persistent record storage are not implemented in the current prototype.
- The project is intended for learning and demonstration, not production use without further development and security testing.
